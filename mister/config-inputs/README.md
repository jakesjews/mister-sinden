# MiSTer map files for the bridge (VID 16c0 / PID 0f01)

Copy these into `/media/fat/config/inputs/` on the MiSTer.

- `input_16c0_0f01_v3.map` — the **global** map. Main_MiSTer only gives a device a player slot
  when a pressed button matches one of this map's D-pad/A/B/X/Y/L/R/Select/Start entries, so
  without it the gun is ignored by every core. Current layout (Jacob's, defined in the MiSTer
  menu; the bare minimum): D-pad 0x125–0x128; rear-left 0x122 → A; rear-right 0x123 → B;
  front-left 0x121 → Select; front-right 0x124 → Start. The trigger (0x120) and pump-action
  (0x129) are not in it, so press a side button or the D-pad once after loading a core to claim
  Player 1; the OSD is opened from the keyboard. Axes are deliberately unmapped: Main routes a
  light gun's X/Y itself.
  Bridge button numbering (what the gadget emits): 1 trigger 0x120, 2 front-left 0x121,
  3 rear-left 0x122, 4 rear-right 0x123, 5 front-right 0x124, 6–9 up/down/left/right 0x125–0x128,
  10 pump-action 0x129 — the order Sinden's README assumes ("A to front left, B to back left,
  Select to back right, Start to front right").
- `<CORE>_input_16c0_0f01_v3.map` — per-core button maps, taken from Sinden's
  MiSTerSindenDriver repo and renamed from their fork's core names to the stock ones
  (NES, SNES, MegaDrive, MegaCD, SMS, PSX, PSX_Turbo, ATARI7800). They bind the trigger to the
  core's gun button (e.g. NES "Zapper/Vaus Btn"). `NES_…` is Jacob's own remap saved from the
  core's "Define NES buttons". Per-core OSD options still have to be set (NES: Peripheral =
  Zapper(Joy1) **and** Zapper Trigger = Joystick, then Save Settings).
